## 🎯 What is GLEE GAMES?

GLEE GAMES turns a single device into a social party-game experience.

Instead of requiring every player to download an app, create an account, or connect to an online lobby, players can simply gather around one device and play together using a **pass-and-play** format.

The experience is designed to be:

* ⚡ Fast to start
* 🎮 Easy to understand
* 👥 Social and interactive
* 📱 Mobile-friendly
* 🌍 Multilingual
* 🔊 Interactive with sound and feedback

---

# 🎮 The Games

GLEE GAMES currently features **five playable social games**, each built around a different type of interaction.

---

## 🕵️ Spy Game

A social deduction game where one player secretly becomes the spy.

Players privately reveal their roles, discuss the situation, and attempt to identify the spy before the spy discovers the location.

### Key Mechanics

* Private role reveal
* Pass-and-play privacy
* Countdown timer
* Discussion
* Voting
* Spy location guessing

# ✨ Features

### 👥 Pass-and-Play Multiplayer

Designed for groups sharing one device.

Players can pass the phone or tablet from one person to another during gameplay.

### 🚫 No Account Required

Players can start playing without creating an account or profile.

### ⚡ Quick Start

The experience is designed to minimize setup and get groups into the game quickly.

### 🔊 Interactive Sound

Browser-based audio effects provide feedback during important interactions and game moments.

### 📳 Haptic Feedback

Supported devices can provide vibration feedback during selected interactions.

### ⏱️ Timed Gameplay

Several games use timers and countdowns to create pressure and maintain a fast pace.

### 📱 Responsive Interface

The interface adapts to modern mobile and desktop screen sizes.

### 🌐 Multilingual

GLEE GAMES supports multiple interface languages and is designed for an international audience.

### ↔️ Arabic RTL

Arabic is supported with right-to-left interface behavior.

### 📲 PWA

The application includes Progressive Web App capabilities for a more app-like web experience.

# 🚀 Getting Started

## Requirements

Before running the project locally, install:

* Node.js
* npm
* Git

## Clone the Repository

```bash
git clone https://github.com/sirinemoussoui-debug/GLEE-GAMES.git
```

## Enter the Project

```bash
cd GLEE-GAMES
```

## Install Dependencies

```bash
npm install
```

## Start Development

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
