# Kari Games 🎮

Kari Games is a multiplayer social party games web application designed for friends, students, parties, and social gatherings.                                                      
 
*Features=
- 🎮 Multiplayer party games
- 👥 Support for multiple players
- 🕵️ Spy Game
- 😂 Who's Most Likely To
- 💣 Word Chain Bomb
- 🧠 Campus Trivia Duel
- 🧩 Emoji Decoder
- 🌍 Arabic, English, and French support
- ↔️ Full RTL support for Arabic
- 🔊 Sound effects and mute controls
- ⏱️ Timers and scoring systems
- 📱 Responsive design for mobile and desktop

 *Play=

Choose a game, add your players, and start playing!

Built with Google AI Studio and synced with GitHub.
